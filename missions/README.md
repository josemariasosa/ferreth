# Missions

Mission definitions live here. Each mission specifies:

- Objective and success criteria
- Authorized files and scope
- Agent role assignments
- Acceptance tests and verification requirements

## Mission Structure

Each mission file should include:

```markdown
# Mission X - <title>

## Objective
<What this mission accomplishes>

## Scope
<Files/areas this mission can modify>

## Constraints
<Technical, temporal, or resource limits>

## Acceptance Criteria
<MUST have concrete, testable criteria>
- [ ] Criterion 1
- [ ] Criterion 2
```
