# Phase 1.4 — Symbolic PUSH1 composition

## RF-012 — Repeated short PUSH1 fragments bind to shared publishers

Can the public `asm-rs 0.2.0` API compose repeated production-shaped PUSH1
fragments with unique local labels and shared publishers while preserving
ADR-001 behavior? The test uses `Arch::Rv64` at `0x80000000`, with default
features disabled and `std` and `riscv` enabled. The frozen workspace selected
`rvemu 0.0.11` for short runs. The production compiler is the equivalence
control. The existing conformance suite exercises REVM 43.0.3 on Cancun.
No EELS or frame-gas comparison was needed for this composition experiment.
[Experiment](../tests/symbolic_push1.rs) · [ADR-001](../../../../docs/adr/001-evm-guest-state-abi.md) · [Architecture research](../../ferreth-linking-architecture.md)

### Source-derived contract

- `s0` (`x8`) holds the fixed base `0x80101000`, and `s1` (`x9`) is
  the next free slot in the ascending 1,024-word stack. A word is 32 bytes,
  with four little-endian 64-bit limbs, least-significant limb first.
  PUSH1 preserves `s0` and the native stack pointer and uses `t0` as scratch.
- `lui t0, 8` and `add t0, s0, t0` form the exclusive stack bound
  `0x80109000`. At fragment byte offset 8, unsigned `bgeu s1, t0, 32`
  jumps to the trampoline at byte offset 40 before any write or change
  to `s1`. The standalone generator's trampoline is the self-jump
  `jal zero, 0`. On success, `addi` loads the unsigned byte, the four
  stores write it and three zero limbs, and `s1` advances by 32. The
  `jal zero, 8` at offset 36 skips the trampoline and resumes at
  byte offset 44. [Generator](../../../../crates/ferreth-compiler/src/rv64/opcodes/push.rs) · [Fragment tests](../../../../crates/ferreth-compiler/tests/rv64_push1.rs)
- For PUSH1-only bytecode at EOF, production generates the bodies separately,
  places the two publishers, patches each trampoline and reconstructs its
  numeric JAL in source. It reassembles that source to check the patched bytes
  and validates guest layout. With explicit STOP it uses the mixed production
  path. [Compiler](../../../../crates/ferreth-compiler/src/compiler.rs) · [Program tests](../../../../crates/ferreth-compiler/tests/rv64_push1_program.rs)
- The publishers derive metadata base `0x80100000` from `s0 - 4096`.
  Both store `final_s1` at +16, then `exception_code` at +8, then status
  at +0 to mark publication. Normal uses code 0 and status 1, and overflow
  uses provisional code 1 and status 2. Both end in `jalr zero, -4(t1)`
  to the reserved `0x800ffffc` sentinel. The host stops before fetching
  the sentinel, validates the published result and derives depth from
  `final_s1`. [Publishers](../../../../crates/ferreth-compiler/src/compiler.rs#L614) · [ADR-001 publication](../../../../docs/adr/001-evm-guest-state-abi.md#6-initialization-and-termination-contract)

### Composition and independent verification

The experiment writes the original stack and publisher instructions directly
into one source string. Each occurrence names its entry, local overflow
trampoline and success continuation using the occurrence index. The branch
targets its own trampoline, and the success JAL targets the continuation
label at the next fragment's entry or at `normal_exit` after the last push.
Each trampoline names `push1_stack_overflow_exit`. Label definitions emit
zero bytes, including the pairs of names that share a PC at a continuation.
The pinned `Assembler::new(Arch::Rv64).base_address(...).emit(...)`
followed by `finish()` yields one image and the final label addresses.
There are no machine-word patches or source-prefix/suffix replacements.
[Phase 1.1 result API](1.1-assembler-api.md)

The verifier takes publisher and local label PCs from `label_address()`.
It reads individual little-endian instruction words, checks BGEU's opcode,
condition and registers and checks every JAL for opcode `0x6f` and
`rd=x0`. It reconstructs and sign-extends each immediate using the
Phase 1.3 method, adds it to the instruction's own PC and compares the
result to the intended label PC. Known PUSH1 byte offsets check instruction
placement within a fragment. The verifier reads no relocation records
and derives no publisher address from a source instruction count. Every
direct site and target is four-byte aligned and contains a full instruction
inside the image. The image ends before the reserved exit slot. The two
fixed publisher JALRs reach that dedicated sentinel under the ABI
register invariant. [Phase 1.3 verifier](1.3-independent-verification.md)

### Standalone comparison probe

Save the Rust block to `$out/compare.rs` after the workspace build.
The probe reuses the actual test specimen and the workspace-built rlibs
without adding a dependency to the spike. Execute it from the temporary
directory to contain rvemu's working-directory writes.

```rust
include!(env!("FERRETH_SYMBOLIC_PUSH1"));

use alloy_primitives::U256;
use ferreth_compiler::{
    compiler::compile_evm_bytecode,
    execution::random_u256,
    orchestrator::execute_guest_evm_bytecode_with_initial_stack,
    rv64::{
        executor::{IntegerRegister, Rv64Executor, RvemuExecutor},
        guest::{initialize_guest_state, read_guest_result, write_evm_word},
    },
};

#[test]
fn compare_with_production() {
    let (source, symbolic) = assemble_pushes(&[2, 3]);
    let production = compile_evm_bytecode(&[0x60, 2, 0x60, 3]).unwrap();
    println!("Production assembly:\n{}", production.assembly());
    let bytes: String = production.machine_code().iter().map(|b| format!("{b:02x}")).collect();
    println!("Production bytes: {bytes}");
    println!("Production size: {} bytes, {} words", bytes.len() / 2, production.instruction_limit());
    println!("Production publisher PCs: {:08x?}", production.termination_entry_pcs());
    println!("Same source: {}; same bytes: {}", source == production.assembly(),
        symbolic.bytes() == production.machine_code());

    let mut seed = 42;
    let full: Vec<_> = (0..1024).map(|_| random_u256(&mut seed)).collect();
    for (immediates, initial, counts) in [
        (&[2, 3][..], &[][..], (20, 7)),
        (&[2][..], &[][..], (10, 7)),
        (&[2][..], &full[..], (4, 8)),
    ] {
        let bytecode: Vec<_> = immediates.iter().flat_map(|value| [0x60, *value]).collect();
        let (_, artifact) = assemble_pushes(immediates);
        let publishers = [NORMAL, OVERFLOW].map(|name| artifact.label_address(name).unwrap());
        let mut executor = RvemuExecutor::new().unwrap();
        executor.load_code(artifact.bytes()).unwrap();
        executor.write_memory(EXIT, &0x0010_0073_u32.to_le_bytes()).unwrap();
        initialize_guest_state(&mut executor).unwrap();
        for (slot, word) in initial.iter().copied().enumerate() {
            write_evm_word(&mut executor, slot, word).unwrap();
        }
        let base = 0x8010_1000;
        executor.write_register(IntegerRegister::EVM_STACK_NEXT_FREE, base + initial.len() as u64 * 32);
        let limit = (artifact.len() / 4) as u64;
        let body = executor.execute_until(ENTRY, &publishers, limit).unwrap();
        let publisher = executor.execute(body.exit_pc, EXIT, limit - body.executed_instructions).unwrap();
        let guest = read_guest_result(&mut executor, &publisher).unwrap();
        let expected: Vec<_> = if initial.is_empty() {
            immediates.iter().copied().map(U256::from).collect()
        } else {
            initial.to_vec()
        };
        assert_eq!(guest.stack(), expected);
        assert_eq!(guest.final_s1(), base + expected.len() as u64 * 32);
        assert_eq!((body.executed_instructions, publisher.executed_instructions), counts);
        let is_full = !initial.is_empty();
        assert_eq!(body.exit_pc, publishers[usize::from(is_full)]);

        for stop in [false, true] {
            if stop && immediates.len() != 1 {
                continue;
            }
            let mut control = bytecode.clone();
            if stop {
                control.push(0);
            }
            let baseline = execute_guest_evm_bytecode_with_initial_stack(&control, initial).unwrap();
            assert_eq!(&guest, baseline.guest_result());
            let metrics = baseline.instruction_metrics();
            let expected_body = counts.0 + u64::from(stop && !is_full);
            assert_eq!((metrics.opcode_body(), metrics.guest_termination()), (expected_body, counts.1));
            println!(
                "PUSH1 {immediates:?}, initial depth {}, production STOP={stop}: {:?}, exception={}, final_s1={:#x}, {} stack words match, symbolic publisher={:#x}; symbolic {counts:?}, production {:?}",
                initial.len(), guest.status(), guest.exception_code(), guest.final_s1(),
                guest.stack_depth(), body.exit_pc, (metrics.opcode_body(), metrics.guest_termination())
            );
        }
    }
}
```

## Implications and exit gate

**Met for Phase 1.4.** The composition used indexed labels and the
assembler's final bytes and label addresses. The research regressions
exercise the one-, two- and five-fragment layouts, all direct
destinations, unchanged PUSH1 effects and four-byte executable bounds.
The separate runtime probe establishes short normal and exceptional parity
under ADR-001 on one host and backend. These are bounded research checks.
A future composer would need equivalent regression evidence through its
normal entry points. Long-range symbolic guest execution and an actually
taken distant exception remain Phase 1.5 work. LF-026 and LF-027 remain
open in production.
