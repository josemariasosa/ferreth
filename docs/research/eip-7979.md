This is a minimal change to the Ethereum Virtual Machine (EVM) to support calls and returns. Compilers must now synthesize calls with dynamic jumps: the flow of control is obscured, and every analysis pays. These instructions make calls explicit — saving code and gas, putting return addresses securely beyond the reach of code, and supporting fully static control flow — code that can be validated, compiled, and analyzed in time linear in its size.

This proposal introduces three new control-flow instructions to the EVM:

CALLSUB transfers control to the destination on the data stack.
CALLDEST marks the destination of a subroutine entry.
RETURNSUB returns to the PC after the most recent CALLSUB.
These changes are backwards compatible: the instructions behave identically wherever they appear.
